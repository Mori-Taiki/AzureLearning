

Active Directory は、ID 管理の中核となるサービスを提供します。AD DS は従来型のオンプレミス ソリューションであるのに対し、Microsoft Entra ID はクラウドベースのソリューションです。Microsoft Entra ID は、最初はクラウドベースのアプリの認証を容易にするために導入されることが多いですが、インフラ全体に認証サービスを提供する能力を備えています。両者は似たソリューションを提供しますが、それぞれ異なる機能を持ち、最良の組み合わせを実現するために併用されることもよくあります。Microsoft Entra ID は無料サービスとして提供されており、組織のニーズに応じて追加機能を利用できる有料レベルも用意されています。
