Azure Cloud Shell は、Web ブラウザーからアクセスできるコマンドライン環境です。この環境を使用して、VM、ストレージ、ネットワークなどの Azure リソースを管理できます。Azure CLI や Azure PowerShell を使う場合とまったく同じように操作できます。

Cloud Shell は Microsoft が管理しているため、どのブラウザーからでも、常に最新バージョンの Azure CLI と PowerShell モジュールをすぐに利用できます。モジュールを最新の状態に保つことを気にする必要はありません。Cloud Shell では、ブラウザーを開いてサインインするだけです。それだけで、自分のアカウントのアクセス許可と、アクセスできるリソースに完全に接続されたコマンドライン環境を利用できます。しかも、これらはすべて、既定で保存時の二重暗号化に準拠したインフラストラクチャ上で動作します。追加の操作は一切必要ありません。

Azure Cloud Shell には、SSH キーやスクリプトなどのファイルを保持するためのクラウド ストレージも用意されています。この機能により、セッションをまたいで、また異なるマシンからでも、重要なファイルにアクセスできます。さらに、Cloud Shell エディターを使用すると、このクラウド ストレージに保存されたスクリプトなどのファイルを、Cloud Shell のインターフェイスから直接編集できます。
