Azure Storage は、開発者が安全なアプリケーションを構築できるように、連携して機能する包括的なセキュリティ機能を提供しています。

このモジュールでは、あなたの会社は個人情報を含む機微なデータを Azure Storage に保存しています。このデータは、社内と外部のアプリケーション開発者の両方が利用します。あなたは、すべての利用者に対してデータを安全に保つ責任を負っています。情報への安全なアクセスを付与するための構成ソリューションの提供を任されています。

## 学習の目標

このモジュールでは、次のことを学びます。

- URI (Uniform Resource Identifier) と SAS のパラメーターを含む、共有アクセス署名を構成する。
- Azure Storage の暗号化を構成する。
- カスタマー マネージド キーを実装する。
- Azure Storage のセキュリティを改善する方法を提案する。

## 評価されるスキル

このモジュールの内容は、[試験 AZ-104: Microsoft Azure Administrator](/credentials/certifications/resources/study-guides/az-104) の準備に役立ちます。
