このモジュールでは、Azure Storage と、ストレージ アカウントの作成方法について学びました。

**このモジュールの要点は次のとおりです。**

- Azure Storage は、仮想マシン データ、非構造化データ、構造化データなど、さまざまな種類のデータに応じた幅広いストレージの選択肢を提供します。

- ストレージ アカウントにはいくつかの種類があり、それぞれに独自の機能と価格モデルがあります。適切なストレージ アカウントの種類を選ぶには、アプリケーション固有の要件を考慮することが重要です。

- Azure Storage は、Azure Blob Storage、Azure Files、Azure Queue Storage、Azure Table Storage の 4 つのデータ サービスを提供します。各サービスは異なる種類のデータに最適化されており、それぞれ独自の利用ケースと利点があります。

- レプリケーションは、データの持続性と高可用性を確保するための重要な検討事項です。Azure Storage には、要件に応じて選べる複数のレプリケーション戦略があります。

- カスタム ドメインとセキュアなエンドポイントを構成することで、Azure のストレージ アカウントへのアクセスと保護を実現できます。

- What is an Azure storage account? What type of storage accounts are available?

- Explain for a nontechnical person Azure data redundancy for storage accounts.
