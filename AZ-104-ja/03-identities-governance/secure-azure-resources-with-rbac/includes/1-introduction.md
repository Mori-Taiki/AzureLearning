クラウドを利用するあらゆる組織にとって、仮想マシン、Web サイト、ネットワーク、ストレージといった Azure リソースの保護は極めて重要な仕事です。データと資産を保護しつつ、従業員やパートナーには業務の遂行に必要なアクセスを与えたいはずです。Azure RBAC は、誰が Azure リソースにアクセスできるか、そのリソースで何ができるか、どの範囲にアクセスできるかを管理するのに役立つ、Azure の認可システムです。

あなたは、回路設計と電気設計を専門とするエンジニアリング会社 First Up Consultants に勤めているとしましょう。同社は、複数のオフィスや他社との共同作業をしやすくするために、ワークロードと資産を Azure に移行しました。あなたは First Up Consultants の IT 部門で働いています。会社の資産を安全に保ちながら、ユーザーには必要なリソースへのアクセスを許可する責任があります。Azure RBAC が Azure のリソース管理に役立つと聞きました。

このモジュールでは、Azure RBAC を使って Azure のリソースへのアクセスを管理する方法を学びます。

## 学習の目標

このモジュールでは、次のことを行います。

- 自分自身と他のユーザーのリソースへのアクセスを確認する。
- リソースへのアクセスを付与する。
- Azure RBAC の変更のアクティビティ ログを確認する。
