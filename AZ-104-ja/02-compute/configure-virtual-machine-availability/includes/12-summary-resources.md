Azure には、仮想マシンの高可用性を実現する選択肢がいくつも用意されています。可用性セット、可用性ゾーン、Azure 仮想マシン スケール セットを使うことで、高可用性を実現できます。

このモジュールでは、更新ドメインと障害ドメインを備えた可用性セットと可用性ゾーンを使って、仮想マシンの可用性を構成する方法を学びました。仮想マシンの自動スケールの方法と、垂直・水平スケーリングの構成方法も確認しました。また、ストレージの回復性やスケーラビリティの選択肢を含めて、仮想マシン スケール セットの実装方法を振り返りました。

このモジュールの要点は次のとおりです。

- Azure 仮想マシン スケール セットを使うと、同一構成の仮想マシン グループのデプロイと管理が行え、大規模サービスの構築が容易になります。

- 仮想マシン スケール セットの自動スケールは、ワークロードの需要に基づいてインスタンス数を自動調整することで、パフォーマンスの最適化に役立ちます。

- 可用性セットと可用性ゾーンは、仮想マシンの高可用性と耐障害性を実現するための Azure の重要な機能です。

## Copilot でさらに学ぶ
Copilot は、Azure インフラストラクチャ ソリューションの構成を支援してくれます。より詳しい情報が必要な製品やサービスについて、Copilot に比較、推奨、解説、調査を頼めます。Microsoft Edge ブラウザーを開いて右上の Copilot を選ぶか、copilot.microsoft.com にアクセスしてください。少し時間を取って次のプロンプトを試し、Copilot で学びを深めましょう。

- How do virtual machine scale sets work with Azure availability zones and sets?

- What is the difference between manual and autoscaling of Azure virtual machines?
